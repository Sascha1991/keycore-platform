## Architecture

KS-08-04 adds `CustomerKeyAccessService`, a thin application composition layer:

```text
authenticated principal
-> owned account order projection
-> fulfillment/order eligibility
-> CustomerKeyDeliveryService.prepareDelivery / executeDelivery
```

The authoritative decrypt, one-time capability, claim/acknowledge, stale
in-flight and manual-review behavior remains in KS-07-05 customer key delivery.
No parallel decrypt service, key vault, WooCommerce repository or plaintext key
endpoint was added.

## Authorization And Eligibility

Key access is eligible only when:

- the principal is authenticated;
- the account repository confirms the order is owned by that customer;
- the fulfillment reference belongs to that exact order;
- `keyAccessAvailable` is true from the complete metadata state;
- KS-07-05 delivery authorization independently authorizes the same customer,
  order and fulfillment context.

Unknown order, wrong owner, legacy/unclaimed order, missing fulfillment,
fulfillment/order mismatch and non-ready fulfillment fail closed without
decrypting.

## Transport Integration

`CustomerAccountTransportHandler` now models explicit POST-style key access
actions:

- `prepareKeyAccess`;
- `executeKeyAccess`.

They reuse KS-08-03 Origin, CSRF, credential extraction, body-size, strict DTO,
safe correlation and hashed rate-limit conventions. They do not expose
production HTTP routes.

## Tests

Focused tests cover:

- synthetic account metadata reports key access available without decrypting;
- explicit prepare creates a one-time delivery capability without decrypting;
- explicit execute crosses the KS-07 delivery boundary and delivers exactly
  once;
- replay, concurrency, fresh in-flight and stale in-flight manual-review
  behavior;
- wrong owner, unknown, unclaimed and mismatched fulfillment enumeration-safe
  denial;
- non-ready, manual-review, invalid-principal and unverified denial;
- WooCommerce-style input cannot authorize key access;
- Origin, CSRF, rate-limit and authority-field failures before decrypt;
- no Kinguin/supplier calls.
