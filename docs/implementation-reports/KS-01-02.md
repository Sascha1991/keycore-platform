## Dependency Boundary Design

The core package is split into:

- `packages/platform/src/domain`: immutable value types, state names, evidence DTOs, and safe validation helpers;
- `packages/platform/src/ports`: supplier-neutral ports and future adapter contracts;
- `packages/platform/src/contracts.ts`: public export surface for the contract skeleton.

Boundary tests scan core source files and fail if they import WordPress, WooCommerce, Kinguin, Stripe, Redis, PostgreSQL clients, network clients, or HTTP modules. Supplier contracts are also checked for Kinguin-specific names.

## Known Limitations

- Contracts are intentionally skeletal and do not implement business workflows.

- Persistence and queue ports define boundaries only and do not connect to PostgreSQL or Redis.
- Storefront gateway defines a neutral boundary only and does not import or execute WordPress/WooCommerce behavior.
