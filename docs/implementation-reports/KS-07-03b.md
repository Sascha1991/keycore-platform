## Read-Only Transport

The verification uses `KinguinLiveReadonlyGuardedTransport` with explicit
allowlisting. Allowed endpoints are:

- `GET /v1/products`
- `GET /v2/products/{productId}`
- `GET /v1/regions`
- `GET /v1/platforms`
- `GET /v1/genres`

Forbidden behavior:

- `POST`, `PUT`, `PATCH`, `DELETE`
- `/order`
- `/keys`
- `/keys/return`
- non-HTTPS URLs
- unexpected host or base path
- redirects to forbidden host/path

The transport records safe method/path request summaries and exposes:

- `mutationRequestCount`
- `forbiddenRequestCount`
- `keyRetrievalRequestCount`

## Dry-Run Preparation Flow

The command `npm run kinguin:verify-procurement-dryrun` refuses execution unless
all local live-read-only requirements are present:

- `KEYCORE_ALLOW_KINGUIN_LIVE_READONLY=true`
- `KINGUIN_ENVIRONMENT=PRODUCTION`
- `KINGUIN_API_BASE_URL=https://gateway.kinguin.net/esa/api`
- `KINGUIN_API_KEY` loaded from local environment or ignored `.env`
- Kinguin production purchasing remains disabled in configuration

When enabled, the command:

1. authenticates with `GET /v1/products?page=1&limit=1`;
2. reads at most 20 product records with `GET /v1/products?page=1&limit=20`;
3. reads reference data from regions, platforms and genres;
4. resolves a candidate through `SupplierOfferId -> SupplierProductId`;
5. refreshes the exact mapped product through `GET /v2/products/{productId}`;
6. evaluates Germany eligibility with `de-eligibility-v1`;
7. exercises pricing with synthetic verification-only fee/tax assumptions;
8. builds the documented Kinguin order payload locally;
9. returns `purchaseMutation: "NOT_SENT"` and a non-secret request fingerprint.

## Real vs Synthetic Inputs

Real read-only inputs:

- Kinguin product identifiers
- Kinguin offer identifiers
- Kinguin current offer price in EUR
- Kinguin availability and region evidence
- Kinguin reference data

Synthetic verification-only inputs:

- tax treatment: `SYNTHETIC_VERIFICATION_ONLY`
- fee treatment: zero known fixture fee
- pricing policy: `synthetic-verification-only`
- dry-run-only `orderExternalId` beginning with `keycore-dryrun-`

The resulting profitability check is a technical path verification only. It is
not production-valid margin, VAT, tax or commercial approval evidence.
