## Implementation Summary

- Added a versioned, generic job envelope with correlation ID, idempotency key, attempt metadata, schema version and safe payload validation.
- Added fail-closed payload guards that reject forbidden sensitive field names at top level and nested positions.
- Added generic retry policy helpers with maximum attempts, capped exponential backoff, jitter and retryability checks.
- Added in-memory observability hooks for queue, outbox, retry and reconciliation metric events.
- Added PostgreSQL transaction support for atomic repository operations.
- Added durable outbox repository operations for creation, claiming, publication, retry scheduling and manual-review escalation.
- Added reconciliation repository operations for creation, claiming, completion, failure retry scheduling and manual-review escalation.
- Added Redis queue adapter behind the queue port for delivery only; durable intent remains in PostgreSQL.
- Added generic outbox dispatcher that publishes claimed PostgreSQL outbox records and keeps records retryable when publication fails.
- Added generic worker lifecycle support for startup, graceful shutdown, handler registration, correlation propagation, health state and safe error handling.
- Added CI Redis service configuration for Redis-backed integration tests.
